# Original fifty: terrain rework

Local review: http://127.0.0.1:4174/original-worlds.html

The original 50 retain their puzzle sequences, skill budgets, campaign order and permanent save IDs. This pass reworks their physical surrounds, material rendering and review presentation. It does not substitute static concept artwork for playable ground.

- Forest: warm painted heartwood, root buttresses, rounded hollows and a moss edge.
- Dunes: bright layered sandstone, broader arch feet and softened cliff edges.
- Mountains: blue glacier facets, white snowcaps, preserved pointed crests and sliding profiles.
- Sweets: existing recognisable giant sweets retained, with new edge lighting that follows excavation.
- Lava: dark fractured obsidian, larger rock supports, quiet blood-red sky, existing contained lava basins retained.

Physical shaping protects recorded route clearance, machinery, exit support and authored mountain/slide edges. Added fragments are retained only when they connect ground or form a substantial buttress. Soft additions are excavatable; steel remains steel. Painting uses the resulting terrain mask. Dirty-region repainting was checked against fresh renders.

## Review controls

All 50 maps have chapter navigation, a full-map focus view, optional full-size scrolling, a solid-terrain overlay, a playable test link and a recorded rescue demonstration. The game simulation drives the demonstrations.

## Verification

237 automated game checks, including a full rescue and deterministic replay for every map. Six browser-rendering checks compare incremental excavation/building against fresh renders and verify level reset. Every map was rendered in the browser for visual review. Build, module syntax and patch checks pass. The original-world rework remains a local preview; the new-world design gallery is published.
